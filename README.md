## AZKi 的日語學習小教室  
這是一個以繁體中文設計的日語互動教學網站，第一堂課從平假名、片假名與基礎單字開始，逐步練習濁音、半濁音、拗音及特殊音。

網站採粉紅色與星空風格，使用 AZKi 貼圖作為課程引導。內容以分段方式呈現，並提供桌機側邊目錄、假名與詞彙語音，以及能即時查看答案解析、重新作答的小測驗。

進入課程時，點擊「進入小教室」會播放 Kawaii AZKi 片頭音檔。假名、單字與例句可分別播放讀音；真人錄音需要連網，缺少錄音時會使用瀏覽器提供的 Google 日語語音（若可用）。

教材依據日文學習 Wiki 整理。網站檔案可由本地開啟，也可部署到 GitHub Pages；網路語音功能需要連線。AZKi 的日語學習小教室
